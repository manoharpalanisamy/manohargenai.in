Harness Orchestrator

Complex questions,
decomposed & synthesized.

Real questions mix product help with live data. A simple router can only pick one path. The Harness orchestrator breaks a question into sub-tasks, routes each to the right capability, runs them in parallel, and synthesizes one clear answer.

01 · DECOMPOSE

Understand

Split a multi-part question into atomic sub-tasks.

02 · ROUTE

Classify

Send each sub-task to Support (RAG) or Insights (SQL).

03 · EXECUTE

Run in parallel

Each capability resolves its own sub-task concurrently.

04 · SYNTHESIZE

Summarize

Combine results into one cited executive summary.

How it works

Reasoning-based RAG
in three steps.

A 300-page manual becomes a compact tree structure — typically 14× smaller than the raw text — that an LLM can reason over in milliseconds.

01

Tree search

The LLM navigates each document's hierarchical tree — titles, page ranges, and summaries — and reasons about which sections are relevant. Runs in parallel across every assigned manual using a fast, low-cost model.

parallelno vectorsno chunking
02

Context extraction

Actual page text is extracted from the identified page ranges with PyMuPDF — no LLM call needed. Source markers are attached for precise citation tracking.

PyMuPDF0 LLM callscitation markers
03

Answer generation

A stronger model synthesizes a detailed, citation-backed answer and streams it token-by-token to the user. Typically 2–5 LLM calls total per query.

streamingNDJSON / SSEcited

Deploy the same knowledge base
everywhere your users are.

web-chat

Web Chat Interface

A full-featured browser app with real-time streaming, a PDF viewer sidebar, clickable citations, and a thinking accordion that shows the AI's reasoning.

  • Inline PDF viewer with page navigation
  • Multiple chat sessions & agent selection
  • Per-query timing & token usage
widget

Embeddable Widget

A ~100–150 KB Lit web component you can drop onto any website — WordPress, ASP.NET, React, or plain HTML — with two HTML tags. Shadow DOM isolated.

  • Zero CSS conflicts (Shadow DOM)
  • Launcher or inline display modes
  • Per-agent citation control
mcp-server

MCP Server

Expose your knowledge base to any AI assistant that speaks Model Context Protocol — VS Code Copilot, Cursor, Claude Desktop — via four retrieval tools.

  • Streamable HTTP transport
  • Context-passing — no double summarization
  • query, list, search, structure tools
cli

Command-Line Tool

A standalone CLI for direct querying — no server infrastructure required. Reads indexes from disk and calls any OpenAI-compatible LLM. Perfect for testing.

  • Single-question or interactive mode
  • No Docker services needed
  • Great for development & CI

Multi-tenant organizations

Each organization gets isolated agents, per-org API keys with role-based access, free-credit allowances, and full usage tracking with visual budget bars.

Security & access control

Cookie + API-key auth, Redis-backed tokens, two-layer agent visibility, and all traffic behind an nginx reverse proxy with Let's Encrypt SSL.

Switch LLMs without code

Gemini, OpenAI, Groq, NVIDIA NIM, OpenRouter, or any OpenAI-compatible endpoint. Use a cheap model for retrieval and a strong one for answers.
